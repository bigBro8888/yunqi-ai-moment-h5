# 云栖大会「我的 AI 云栖时刻」H5 设计规格

## 1. 项目目标

将用户提供的两张 941×1672 竖版视觉稿重构为可交互 H5：保留原稿蓝白、通透、未来园区的视觉气质，同时让核心文字、按钮、标签、照片和装饰组件可以在页面内编辑。页面面向手机浏览和现场传播，打开后应立即呈现完整主视觉，动效轻盈、稳定，不影响阅读。

## 2. 页面状态

- 默认状态：展示人物照片版。
- 无照片状态：隐藏人物，保留中央全息展台与旋转光环。
- 自定义照片状态：用户可从本机选择一张图片替换人物照片。
- 编辑状态：显示轻量编辑工具栏，允许修改、移动、隐藏和恢复组件。
- 展示状态：隐藏所有编辑辅助线与工具，只保留页面和动效。

两种模板共享相同的文字、按钮和动效配置，切换照片状态不会丢失用户修改。

## 3. 视觉结构

页面采用单屏竖版海报结构，设计基准比例为 941:1672，并通过等比缩放适配手机。超宽或桌面屏幕显示居中的手机画布，不拉伸主视觉。

从上到下分为：

1. 顶部大会标识与右上角品牌短句。
2. 主标题「我的 AI 云栖时刻」、轨道线和星芒。
3. 副标题与英文说明。
4. 云栖大会园区背景及人物/空展台区域。
5. 主按钮与次按钮。
6. 活动信息、品牌支持信息与品牌句。
7. 七个能力标签。

园区建筑、现场远景和固定会场字样作为不可编辑背景素材；其余前景内容以 HTML、CSS、SVG 或独立图片组件重建。

## 4. 动效设计

- 全息光环：三层椭圆环独立旋转，速度分别约为 12、18、26 秒一圈，方向交错；局部高光沿环移动。
- 主标题轨道：细线缓慢环绕标题，流光每 4–6 秒经过一次。
- 星芒：低幅度呼吸缩放和透明度变化，不快速闪烁。
- 人物：极轻微上下漂浮，幅度不超过 6px；无照片时不出现空白占位。
- 背景：少量光点缓慢漂移，建筑背景只做极弱的景深呼吸。
- 按钮：触摸时产生短促下压与光泽滑过反馈。

系统启用“减少动态效果”时，停止持续旋转、漂浮和粒子动画，仅保留即时交互反馈。

## 5. 可编辑能力

编辑模式通过右上角悬浮按钮开启，工具栏包含：

- 文本：点击文字直接编辑；支持字号、字重、颜色和对齐方式。
- 组件：选中后可拖动；关键组件可隐藏或恢复。
- 照片：上传替换、调整显示位置、隐藏/显示。
- 模板：人物版与无照片版切换。
- 数据：保存到当前设备、恢复默认值。
- 导出：将当前展示状态导出为 PNG；导出时隐藏编辑工具。

所有可编辑组件均使用稳定 ID。用户修改以 JSON 形式保存在浏览器本地存储中；加载失败时回退到默认配置，不阻断页面显示。

## 6. 交互内容

- 「分享我的云栖时刻」：调用浏览器原生分享；不支持时复制当前页面链接并给出提示。
- 「了解安托未来更多产品」：保留为可编辑链接，默认指向 `https://www.evchetx.com/`，发布前仍可替换为指定产品页。
- 七个能力标签可点击，触发轻量高亮；本版本不增加二级详情页。

## 7. 技术实现

采用静态前端实现，避免服务端依赖，便于直接预览、打包和部署：

- HTML 负责语义化组件结构。
- CSS 负责画布适配、玻璃质感、渐变与关键帧动画。
- SVG 负责可缩放轨道、光环、星芒和线条装饰。
- JavaScript 负责模板切换、照片上传、编辑工具、拖动、保存、恢复、分享与导出。
- 背景与人物素材分层存放；不将整张海报作为唯一背景。

实现优先保证移动端 Safari、微信内置浏览器和 Chromium 系浏览器。页面不依赖外部字体或第三方网络资源，避免现场网络波动导致样式缺失。

## 8. 验收标准

- 竖屏手机打开后，无横向滚动，首屏完整呈现主视觉。
- 人物版与无照片版可即时切换，且不会重置已编辑文字。
- 光环、标题轨道、星芒、粒子和人物漂浮均流畅运行。
- 标题、副标题、活动说明、按钮文字和标签可编辑。
- 组件可拖动、隐藏、恢复；照片可替换。
- 刷新页面后，本机保存的内容仍能恢复。
- 展示模式不出现编辑边框、手柄或工具栏。
- 减少动态效果开启时，无持续动画。
- 完成手机与桌面视口检查，并验证主要交互无控制台错误。

## 9. 明确不包含

- 多人协同编辑或云端数据库。
- 登录、账号和跨设备同步。
- 后台内容管理系统。
- 复杂照片抠图；上传照片默认以圆角/遮罩容器呈现。
- 独立二级产品详情页。
